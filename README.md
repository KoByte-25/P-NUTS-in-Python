**P’NUTS Project** is a Python-based distributed database simulation inspired by Yahoo!’s P’NUTS system. It implements a **master-replica architecture** with schema-based tables, primary key enforcement, and supports core database operations such as **insert, update, select, and delete** with **record versioning**.

The system demonstrates **asynchronous replication** and **timeline consistency**, simulating how distributed NoSQL databases synchronize data across nodes while balancing consistency and scalability. It provides interaction through a **command-line interface, Tkinter desktop GUI, and web interface**, with persistent storage for saving cluster state.

Overall, the project is an educational prototype for understanding **distributed storage, replication, version control, and large-scale database system design**.
